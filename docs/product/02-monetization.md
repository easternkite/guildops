# GuildOps 수익화 전략 (Monetization)

- 문서 버전: 1.0
- 작성일: 2026-02-11
- 기준: B2B2C 형태의 길드 운영 SaaS

## 1) 수익화 원칙

1. 운영 핵심(출석 기록/멤버 관리)은 진입 장벽 완화를 위해 Free에서도 제공.
2. 시간 절약과 리스크 감소를 만드는 고부가 기능(자동화, 분석, 감사)을 유료화.
3. 길드 규모와 운영 복잡도에 맞는 단계형 과금 구조 채택.

## 2) 요금제 구성

| 플랜 | 월 요금(USD) | 대상 | 핵심 포함 기능 | 제한 |
|---|---:|---|---|---|
| Free | 0 | 소규모 길드/테스트 | 멤버/이벤트/공지/기본 출석 | 길드 1개, MAU 50, 보관 30일 |
| Pro | 29 | 중간 규모 운영 길드 | 고급 출석(상태/노트), 역할 기반 정책, 기본 리포트 | 길드 3개, MAU 300 |
| Scale | 99 | 멀티게임/대형 커뮤니티 | 다중 길드 운영, 감사로그 확장, API/Webhook, 우선 지원 | 길드 10개, MAU 1,500 |
| Enterprise | 커스텀 | e스포츠 팀/연합 | SSO, 커스텀 SLA, 데이터 보관 정책 | 별도 계약 |

## 3) 과금 단위

### 3.1 기본 단위

| 항목 | 정의 | 목적 |
|---|---|---|
| 조직 단위(guild) | 관리 대상 길드 수 | 운영 범위 반영 |
| 활성 멤버(MAU) | 30일 내 1회 이상 활동한 멤버 | 실제 사용량 기반 |
| 자동화 실행량 | 출석 배치, 공지 예약, 리포트 생성 수 | 고급 기능 가치 반영 |

### 3.2 사용량 초과 과금(Scale 이상)

| 메트릭 | 기본 포함 | 초과 요금 |
|---|---:|---:|
| 추가 길드 | 10개 | 길드당 $8/월 |
| 추가 MAU | 1,500명 | 100명당 $5/월 |
| 자동화 작업 | 20,000회/월 | 10,000회당 $10/월 |

## 4) CAC / LTV 가정

### 4.1 기준 시나리오 (초기 12개월)

| 지표 | 가정값 | 근거 |
|---|---:|---|
| 유료 전환율(Free→Paid) | 6% | 커뮤니티 운영툴 평균 초기 전환 가정 |
| 월 이탈률(Logo churn) | 4.5% | 초기 PMF 이전 SaaS 보수치 |
| ARPA(유료 평균) | $41 | Pro 중심 + 일부 Scale 혼합 |
| 매출총이익률 | 82% | 소프트웨어/인프라 구조 가정 |
| CAC | $120 | 커뮤니티/콘텐츠/리퍼럴 중심 |

### 4.2 산출

| 항목 | 계산식 | 결과 |
|---|---|---:|
| 고객 평균 수명 | 1 / 월이탈률 | 22.2개월 |
| LTV (Gross) | ARPA × 수명 | $910 |
| LTV (CM 기준) | ARPA × 수명 × 총이익률 | $746 |
| LTV/CAC | LTV(CM) / CAC | 6.2 |
| CAC 회수기간 | CAC / (ARPA × 총이익률) | 3.6개월 |

### 4.3 민감도 분석

| 시나리오 | 월 이탈률 | ARPA | LTV(CM) | LTV/CAC |
|---|---:|---:|---:|---:|
| 보수 | 7% | $34 | $399 | 3.3 |
| 기준 | 4.5% | $41 | $746 | 6.2 |
| 낙관 | 3% | $49 | $1,339 | 11.2 |

## 5) 초기 GTM 전략 (0~6개월)

### 5.1 채널 전략

| 채널 | 실행 방법 | KPI |
|---|---|---|
| Discord 커뮤니티 | 운영 템플릿/봇 연계 가이드 배포 | 데모 신청 수 |
| 길드 리더 인플루언서 | 운영 사례 인터뷰 + 공동 웨비나 | 리퍼럴 가입 |
| 콘텐츠 SEO | "길드 출석 관리" 문제 해결형 아티클 | 오가닉 가입 |
| Product Hunt/커뮤니티 런치 | MVP 공개 + 피드백 루프 | 주간 활성 길드 |

### 5.2 세일즈 모션

| 구간 | 목표 | 전환 액션 |
|---|---|---|
| Awareness | 문제 인식 | 체크리스트/템플릿 제공 |
| Activation | 첫 가치 체험 | 1길드 1주 출석 셋업 마법사 |
| Revenue | 결제 전환 | 제한 해제 + 리포트 고급 기능 업셀 |
| Retention | 재사용 | 주간 운영 리포트 자동 발송 |

| 의사결정 | 기준 |
